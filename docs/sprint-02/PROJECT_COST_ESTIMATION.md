# Project Cost Estimation


Estimasi rupiah untuk **biaya incremental Sprint 2**, menggunakan tarif perencanaan tim mahasiswa sebesar Rp150.000 per manday.

| Komponen | Dasar hitung | Estimasi rendah | Estimasi tinggi | Catatan |
|---|---|---:|---:|---|
| Tenaga kerja tim | 6 MD × Rp150.000/MD | Rp900.000 | Rp900.000 | Shadow cost untuk 48 jam kerja tim; bukan pembayaran tunai anggota. |
| Perangkat lunak/layanan | GitHub Free, Figma Starter, Google Drive | Rp0 | Rp0 | Paket gratis digunakan untuk Sprint 2. |
| Perangkat keras dan internet | Laptop pribadi; alokasi paket internet 3 anggota × Rp50.000 | Rp150.000 | Rp150.000 | Alokasi konektivitas Sprint 2. |
| Pertemuan/transportasi | 2 sesi × Rp75.000 transport lokal | Rp150.000 | Rp150.000 | Sesi validasi dan review pemilik. |
| Overhead | 10% dari biaya tenaga kerja dan operasional | Rp120.000 | Rp120.000 | Cadangan untuk kebutuhan koordinasi/administrasi. |
| **Total estimasi biaya** | Tenaga kerja + operasional + overhead | **Rp1.320.000** | **Rp1.320.000** | Total biaya ekonomi; komponen tenaga kerja berupa shadow cost. |

Biaya operasional tunai diperkirakan **Rp420.000**; ditambah shadow cost tenaga kerja Rp900.000, total biaya ekonomi Sprint 2 menjadi **Rp1.320.000**.
